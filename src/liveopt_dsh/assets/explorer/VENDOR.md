# Browser Libraries

Locally served from published npm packages, with no runtime CDN dependency.

- Apache ECharts 6.1.0: `echarts/dist/echarts.min.js`. Apache-2.0 license and NOTICE included.
- Lucide 1.48.0: `lucide/dist/umd/lucide.min.js`. ISC license included.

The chart uses ECharts scatter selection events. Pareto membership is computed
server-side with the optimizer's existing nondominated sorting implementation.
