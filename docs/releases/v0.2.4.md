# 澜筹 v0.2.4 · Interactive Login

- Rebuilt the shared-server login page with the lanchou identity and a locally served, interactive preview of the public CNC scheduling demonstration.
- The preview includes initial and updated task states, Pareto selection, both objective traces, and actual per-machine job order. It makes no model or optimizer calls and uses no private session data.
- Unauthenticated visitors now see the login page directly at the domain root; successful login returns to the workspace. Valid existing sessions continue directly to the application.
- Added password visibility, login feedback, keyboard-accessible view tabs, responsive layouts and reduced-motion support.
- Kept application APIs, workspace access and result downloads behind the existing signed-cookie gateway. Public asset routes are explicitly allowlisted; dependencies are served locally.
- Retained accounts, API configuration, optimization state and MAPLE numerical behavior.

Shared Linux deployments receive the page with `deploy/sandbox/setup.py --update`. Local one-click launches remain paired directly, without an added account requirement.

The source packages are `lanchou-0.2.4-source.zip` and `lanchou-0.2.4-source.tar.gz`.
