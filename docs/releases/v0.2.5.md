# 澜筹 v0.2.5 · Paper Login and Faster Loading

- Refined the shared-server login with neutral paper surfaces, a subtle embedded texture, system serif headings, and coordinated chart and control colors.
- Raised recorded case playback to 3x by default (1.4 seconds per selection), with 1x/2x/3x choices, synchronized progress, pause controls, and reduced-motion support.
- Embedded minified login CSS, JavaScript and the small transparent logo into the initial HTML. The login form no longer waits for external style, icon or chart downloads.
- Built a smaller ECharts bundle and compact case JSON, with precompressed Brotli/gzip assets, representation-specific ETags and conditional responses. Charts remain asynchronous and load only when their preview approaches the viewport.
- Kept the inline script restricted to its exact SHA-256 Content Security Policy hash. The public asset allowlist, signed sessions, origin checks and protected downloads remain enforced.
- Preserved the MAPLE algorithm snapshot, provider configuration, conversations, uploaded data and optimization state. Preview playback makes no model calls.

Download `lanchou-0.2.5-source.zip` for Windows or `lanchou-0.2.5-source.tar.gz` for Linux. Extract fully, stop the older application process and use the same application home. Launch with `start.cmd` or `bash start.sh`.

For an existing shared Linux sandbox deployment, run the new checkout's `deploy/sandbox/setup.py --update` with the same deployment root. The update retains the existing account, API configuration and data. Local one-click launches do not gain a shared-server login requirement.

Optional desktop clients connect to an existing server and do not bundle the numerical backend. They are built separately for Windows, Linux and macOS.
