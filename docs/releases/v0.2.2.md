# 澜筹 · lanchou v0.2.2

The application formerly called MAPLE Harness is now **澜筹** in Chinese and **lanchou** in English. **MAPLE remains the optimization algorithm.**

- Updated web and desktop branding, browser titles, settings, About, plan explorer, and optimization assistant identity.
- Updated Chinese/English guides and downloadable source package names.
- Preserved tool names, repository URLs, desktop profile, service identifiers, data directories, and existing sessions.
- The numerical optimization core is unchanged. DeepSeek Harness remains pinned to 0.2.1-rc.2; application roles use DeepSeek Flash.
- Included the quick-tunnel failure recovery fix; fixed domain deployments remain the recommended shared-server entry.

Download `lanchou-0.2.2-source.zip` for Windows or `lanchou-0.2.2-source.tar.gz` for Linux. Fully extract the package, stop the previous application, and launch with the same application home. Back up that directory before upgrading. Credentials are not included in the release.

The optional Electron package is a remote client, not the complete backend. Historical demo recordings retain the branding visible when recorded.
