# MAPLE Harness v0.2.0

One-click local web deployment for Windows and Linux, built on the official
DeepSeek Harness 0.2.1-rc.2 host.

## Recommended Downloads

| Platform | Package | After extracting |
|---|---|---|
| Windows 10/11 x64 | `MAPLE-Harness-0.2.0-source.zip` | Double-click `start.cmd`. |
| Linux x64 | `MAPLE-Harness-0.2.0-source.tar.gz` | Run `bash start.sh`. |

These packages install the **complete backend and browser application**, not just
a remote viewer. The first launch downloads private Python and Node.js runtimes.
No administrator privileges, global Python/Node, WSL, or Docker are needed.
Internet access is required for installation and model calls. Linux requires
`curl`, `tar`, CA certificates, and glibc.

In Settings, enter your own DeepSeek API key. All application roles use
`deepseek-flash`. Provider usage is charged to your account. Keep the terminal
open during use and keep the paired launch link private.

## What Is Included

- English and Chinese conversations, with LLM-assisted mapping of Chinese Excel headers.
- File uploads, exact and evolutionary solver choices, and configurable iteration limits (default: 100).
- Background progress, per-objective trajectories, final population and Pareto views.
- Interactive plan selection and downloadable CSV, JSON, and ZIP results.
- Accepted task and search state retained across updates in the same conversation.
- A Chinese garment-export workbook and requests for initialization and a deadline/staffing update.
- A pinned DSH runtime, release manifest, source checksums, and native Windows/Linux CI.

## Upgrade and Platform Notes

Stop the old launcher and back up your application home before upgrading. Extract
the new release and launch it using the same application home. Existing
`liveopt-dsh` installations are not imported automatically. This release does not
change any already-running intranet installation.

Linux arm64 is supported by the launcher but is not in the native CI matrix.
macOS uses the manual installation path. Optional Electron packages are **remote
desktop clients** for an existing MAPLE server; they do not install the local
optimizer or backend. These unsigned clients may require an operating-system
security confirmation.

Generated Workbench code executes as the server user. Deploy for trusted users,
or add suitable isolation before exposing the service to untrusted users.

`SHA256SUMS` covers the attached release packages. Source files and vendored
runtime revisions are recorded in `RELEASE_MANIFEST.json` inside the source
archives. The research experiment repository and caches are not included.
