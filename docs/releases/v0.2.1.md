# MAPLE Harness v0.2.1

This release adds the reusable Linux sandbox deployment and focuses the assistant
on MAPLE optimization. Native Windows/Linux web launchers remain available.

## Changes

- Simplified Chinese by default, with automatic response language and English in Settings.
- MAPLE-specific data, solve/update, and result skills instead of a general coding-agent preset.
- No shell, repository editing, subagents, or repository instruction discovery in the web assistant.
- Linux bubblewrap isolation with a host-side model proxy, authenticated gateway, and persistent user services.
- Optional Cloudflare quick or named tunnels sharing the same sandbox and data as the intranet entrance.
- Passwords are set during local installation. Real API keys and tunnel tokens stay outside the sandbox and repository.
- Credential, private-file, and source-release checks, plus offline web-preset/MCP smoke coverage.

## Packages

| Platform | Package | Start |
|---|---|---|
| Windows 10/11 x64 | `MAPLE-Harness-0.2.1-source.zip` | Extract, then double-click `start.cmd`. |
| Linux x64 | `MAPLE-Harness-0.2.1-source.tar.gz` | Extract, then run `bash start.sh`. |
| Shared Linux server | Same source packages | Follow the [sandbox deployment guide](../../deploy/sandbox/README.md). |

The sandbox server requires Linux. Windows clients can connect to it by browser
or remote desktop. The native Windows backend is not presented as bubblewrap-isolated.

Release assets contain source and checksums only. Existing server data, API keys,
passwords, signing secrets, Cloudflare tokens, private URLs, and backups are excluded.
No production instance is restarted by downloading or publishing this release.
