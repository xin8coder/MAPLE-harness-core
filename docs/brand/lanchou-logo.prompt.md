# lanchou Logo

Current display name: **澜筹·通用运筹智能体**. English name: **lanchou**. Algorithm: **MAPLE**.

The symbol was generated with the built-in image-generation tool, without lettering. Transparent PNG exports are used by the web application, desktop client and product site. The original prompt below predates the final tagline; its production-planning context does not appear as text in the image.

## Original Generation Prompt

Use case: logo-brand.
Asset type: production-ready app icon for 澜筹 (lanchou), a natural-language operations-research agent for real production planning.
Primary request: create ONE elegant, original, memorable symbol that combines a flowing water-wave / lower-case L gesture with a selected optimal route through a small network of decision nodes. It should suggest turning complex production choices into a clear executable plan, not generic chat or robotics. The product's full Chinese display title will be typeset separately in the interface as “澜筹·面向生产落地的运筹智能体”; do NOT draw any text into the icon.
Composition: single centered square-format symbol, compact balanced geometry, consistent bold strokes and clean negative space, with minimal 8% transparent padding. Readable at favicon scale as well as app-header scale. No surrounding box or badge.
Style: polished flat vector-like bitmap brand mark, restrained professional software product identity, crisp precise edges, no photorealism.
Palette: deep teal #087F83 and dark ink #183A43, with one small warm coral #F07B61 chosen-solution node. Use at most these three colors, no gradients.
Background: truly transparent alpha.
Constraints: icon only, no letters, Chinese characters, slogans, numbers, watermark or mockup. No maple leaves, trees, robot faces, chat bubbles, brains, sparkle/star motifs, 3D lighting or shadows. Do not copy existing corporate logos. Deliver one finished logo, not a contact sheet.
